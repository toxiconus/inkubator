MPU6050 / ESP Status

Ten prosty plik HTML pokazuje, jak odczytać stan testowego firmware'u ESP z MPU6050.

Port szeregowy: COM9 (115200)

Plik firmware: mpu6050-test/src/main.cpp

Interwał diagnostyczny: co 5 sekund pojawia się raport stanu ESP oraz skan I2C.

Co odczytujesz

  • start aplikacji: Start MPU6050 test...
  • połączenie MPU6050: MPU6050 OK
  • prędkości obrotu i przyspieszeń: Pitch, Roll, ax, ay, az, gx, gy, gz
  • stan ESP: uptime, freeHeap, temp
  • lista urządzeń I2C wykrytych na magistrali

Jak używać

Otwórz plik status.html w przeglądarce jako dashboard pomocniczy. Dane z ESP będą wyświetlane w konsoli szeregowym.

Jeżeli chcesz, mogę też dodać do firmware prosty serwer HTTP i stronę, która będzie odczytywać status bezpośrednio z ESP.
